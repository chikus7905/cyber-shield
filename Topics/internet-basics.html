Introduction

What is the Internet?

The Internet is a worldwide network that connects millions of computers, phones, and other devices, allowing them to communicate and share information.

Every time you watch a video, send a message, browse a website, or shop online, you are using the Internet.

Connects billions of devices
Shares information worldwide
Works 24 hours a day

How It Works

How the Internet Works

Every time you open a website, your request travels through several steps before the webpage appears on your screen.

Your Device

You type a website address or click a link.

Wi-Fi / Router

Your request is sent through your router.

Internet Provider

Your ISP forwards the request to the Internet.

Website Server

The server processes your request and prepares the webpage.

Webpage Loads

The website is sent back and displayed in your browser.

Understanding the Difference

Browser vs Search Engine

Many people think a browser and a search engine are the same thing, but they have different roles.

Web Browser

A web browser is software that lets you open and view websites on the Internet.

Examples

  • Google Chrome
  • Mozilla Firefox
  • Microsoft Edge
  • Safari

Search Engine

A search engine helps you find websites and information on the Internet.

Examples

  • Google
  • Bing
  • DuckDuckGo
  • Yahoo

Easy to remember: A browser is the vehicle you use to travel on the web, while a search engine is the guide that helps you find your destination.

Website Security

HTTP vs HTTPS

Both HTTP and HTTPS are protocols used to transfer data between your browser and a website. The key difference is security.

HTTP

Not Secure
  • Data is not encrypted.
  • Information can be intercepted.
  • Unsafe for passwords and payments.
  • No padlock icon in the browser.

HTTPS

Secure
  • Data is encrypted.
  • Protects sensitive information.
  • Safe for banking and shopping.
  • Shows a padlock icon in the browser.

Safety Tip: Before entering passwords or payment details, make sure the website address starts with https:// and displays a padlock icon in your browser.

Networking Basics

Understanding IP Address & DNS

Every website has a unique address. DNS helps your browser find that address quickly, so you don't have to remember long numbers.

IP Address

An IP (Internet Protocol) address is a unique numerical address assigned to every device connected to the Internet.

Example:

142.250.193.78

📍 Think of an IP address as the house address of a website or device.

DNS

DNS (Domain Name System) converts easy-to-remember website names into IP addresses.

Example:

google.com → 142.250.xxx.xxx

📖 Think of DNS as your phone's contact list. You remember a name, not the phone number.

Easy to Remember: You type a website name like google.com. DNS finds its IP address, and your browser connects to the correct server automatically.

Safe Browsing

Browse the Internet Safely

Following a few simple habits can greatly reduce the risk of cyber attacks and help keep your personal information safe.

Check for HTTPS

Always verify that a website uses HTTPS before entering passwords or payment information.

Use Strong Passwords

Create long, unique passwords and avoid reusing them across multiple websites.

Download Carefully

Download software only from trusted websites and official app stores.

Beware of Suspicious Emails

Avoid opening unexpected attachments or clicking links from unknown senders.

Keep Software Updated

Install browser and system updates regularly to receive important security patches.

Sign Out on Shared Devices

Always log out after using public or shared computers to protect your accounts.

Common Mistakes

Avoid These Internet Mistakes

Trusting Every Website

Not every website is safe or trustworthy. Always verify before sharing information.

Downloading Unknown Files

Files from untrusted sources may contain malware.

Ignoring Browser Warnings

Security warnings are there to protect you from risky websites.

Using an Outdated Browser

Older browsers may have security vulnerabilities.

Using Public Wi-Fi Carelessly

Avoid accessing banking or sensitive accounts on unsecured networks.

Believing Everything Online

Always verify information from reliable sources before sharing it.
